# Edu-Flow Student Management System

Edu-Flow is a web-based Student Management System developed using PHP and modern web technologies. The system is designed to organize student-related information and simplify administrative tasks within an educational environment.

## Features

* **Student Management** – Manage and organize student information.
* **Teacher Management** – Maintain teacher-related records.
* **Institute Management** – Organize institute information.
* **User Management** – Manage system users and their details.
* **User Area Management** – Handle user area-related functionalities.
* **Modular Structure** – Organize application functionality into separate modules for easier maintenance.

## Technologies Used

* **PHP** – Server-side development.
* **JavaScript** – Client-side functionality.
* **HTML5** – Web page structure.
* **CSS3** – Styling and user interface design.
* **SCSS** – CSS preprocessing and styling organization.
* **MySQL** – Database management, if configured in the project.

## Getting Started

### Prerequisites

Before running the project, ensure you have the following installed:

* PHP
* XAMPP or another compatible local PHP server
* A web browser
* MySQL, if required by the application

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Nelu72/Edu-Flow-Student-Managment.git
```

**2. Move the project**

Place the project folder inside the XAMPP `htdocs` directory.

**3. Start the server**

Open the XAMPP Control Panel and start Apache. Start MySQL if your application requires a database.

**4. Configure the database**

If the project uses MySQL, create the required database in phpMyAdmin and import the project database file, if available. Configure the database connection settings as required.

**5. Run the application**

Open your browser and visit:

```text
http://localhost/Edu-Flow-Student-Managment/
```
